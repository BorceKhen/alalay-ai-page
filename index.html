Problem statement

Inclusive education promotes equal learning opportunities for all individuals, regardless of ability, background, or disability. Despite this goal, educational systems still struggle to deliver learning experiences that effectively accommodate diverse learner needs, particularly those of individuals with learning and visual disabilities. In the Philippines, inclusive education is supported by legislative measures such as Republic Act No. 7277 and Republic Act No. 11650, which advocate equal access to quality education for persons with disabilities. However, implementation remains inconsistent, as many educational institutions still rely on modifying existing instructional materials rather than redesigning curricula and learning environments to be inherently accessible (Jazmines et al., 2025). Consequently, learners with disabilities, particularly those with dyslexia, complete blindness, color blindness, and low vision, often experience limited access to appropriate learning resources and accessible educational technologies (Ocampo et al., 2023; Albuquerque et al., 2025). Existing digital learning platforms further compound these challenges by offering limited accessibility features and standardized learning experiences that do not adequately address individual learning needs, resulting in reduced learner engagement, lower comprehension, and suboptimal learning outcomes (Iliska & Gudoniene, 2025; Bharathi et al., 2026). Furthermore, disability-specific systems are still designed around one impairment at a time, which may limit their ability to accommodate individuals with multiple or overlapping accessibility needs (Theil et al., 2023).

In response, this study proposes a cross-platform, machine learning-driven adaptive learning system to support inclusive education for individuals with reading and visual disabilities. The proposed platform allows users to import educational resources, including .docx, .pdf, and .pptx files. It automatically generates personalized learning materials, such as flashcards and quizzes, tailored to users' accessibility requirements and learning profiles. By analyzing Human–Computer Interaction (HCI) telemetry, the system continuously identifies user interaction patterns. It then applies adaptive recommendation techniques to personalize interface configurations, accessibility features, and learning content based on users' preferences and learning behaviors. By integrating machine learning techniques, accessibility standards, and adaptive interface design principles, the proposed platform aims to improve accessibility, learner engagement, and educational outcomes while promoting a more inclusive digital learning environment.

To address the general problem, this study aims to address the following research questions:

  1. How can a cross-platform, machine learning-driven adaptive learning system, integrated with accessibility tools, be designed and developed to provide accessible, user-centered, and multimodal interaction features for individuals with dyslexia, complete blindness, low vision, and color blindness?
  2. How can machine learning, natural language processing, and deep learning models be implemented and fine-tuned to support adaptive reading functionalities, including text simplification, text extraction, learning content generation, readability classification, comprehension prediction, text-to-speech, interface personalization, and personalized recommendations?
  3. How accurately can supervised and reinforcement machine learning algorithms predict optimal interface configurations and content difficulty based on real-time user interaction data?
  4. How effectively do the implemented machine learning, natural language processing, and personalization models perform based on established evaluation metrics?
  5. To what extent does the integrated ALALAY-AI adaptive reading platform improve reading comprehension, accessibility, and user engagement compared with conventional non-adaptive digital reading platforms?

Objectives

General objective. To design, develop, and evaluate a cross-platform, intelligent machine learning-driven adaptive reading platform that enhances accessibility and reading comprehension for individuals with dyslexia, complete blindness, low vision, and color blindness through personalized content transformation, integration of accessibility tools, content simplification, and dynamic interface adaptation.

Specific objectives. Specifically, this study aims to address the following objectives:

  1. Adaptive Cross-Platform Environment: Design and develop an accessible, user-centered web learning platform supporting multimodal interaction for learners with dyslexia, complete blindness, low vision, and color blindness.
  2. Document Processing & Text Simplification: Implement and fine-tune machine learning, natural language processing, and deep learning models for document text extraction (UHTEM: PaddleOCR + LayoutLMv3) and tiered text simplification (Groq/GPT-OSS-20B, Gemini Flash, Local T5).
  3. Multimodal Assistive Tools: Integrate customizable typography, Daltonization color vision deficiency filters, Azure Neural TTS, reading rulers, and screen reader compatibility.
  4. Reinforcement Learning Personalization: Formulate, train, and deploy a Deep Q-Network (DQN) engine to sequentially adapt interface configurations and content difficulty based on real-time user interaction telemetry.
  5. Empirical Performance Evaluation: Benchmark model performance using established metrics including Character/Word Error Rates (CER/WER), SARI, BLEU, and cumulative reinforcement learning rewards.
  6. User Validation & Technical Compliance: Evaluate reading comprehension improvement across 50 participants, conduct User Acceptance Testing (UAT), and validate ISO/IEC 25010 technical quality and W3C accessibility compliance with 10 IT experts.

System Features & Screenshots

Interactive, accessible interfaces engineered to bridge accessibility barriers through state-of-the-art machine learning and personalized assistive controls.

Feature 01

Accessible Study Workspace & Multi-Format Decks

A high-contrast, keyboard-navigable learning workspace that organizes user study sets, recent decks, and interactive study modes. Fully responsive and compliant with WCAG 2.1 AA accessibility guidelines.

  • Three Structured Modes: Descriptive flashcards, multiple-choice quizzes, and Q&A review sessions
  • Live Recency Tracking: Quick-access sidebar with dynamic color indicators and card counters
  • Accessible Layout: High-contrast glassmorphic design with zero visual clutter and intuitive navigation

Feature 02

UHTEM Intelligent Document Ingestion & OCR Pipeline

Converts static, inaccessible academic documents into structured learning cards using the Unified Hybrid Text Extraction Model (UHTEM), combining PaddleOCR (PP-OCRv4) and Microsoft LayoutLMv3.

  • High-Accuracy Extraction: Achieved 98.43% character recognition accuracy and 90.09% word accuracy (9.91% WER)
  • Multi-Format Ingestion: Seamlessly parses complex PDF, DOCX, PPTX, and lecture slide formats
  • Automated Card Generation: Extracts key definitions and terms into bite-sized adaptive flashcards

Feature 03

DQN Reinforcement Learning & Dyslexia Subtype Profiling

Employs a Deep Q-Network (DQN) agent that continuously analyzes Human–Computer Interaction (HCI) telemetry to detect reading friction and recommend clinical deficit-aligned adaptations.

  • Reinforcement Learning Agent: Sequential adaptation achieving 4,860.00 cumulative reward and 75.67% optimal policy match
  • Clinical Deficit Taxonomy: Identifies Visual/Orthographic, Phonological/Decoding, and Rate/Fluency (RAN) friction
  • Behavioral Fatigue Analytics: Real-time tracking of Cognitive Load Index (CLI), Navigation Patterns, and Difficulty Index

Feature 04

Tiered Generative AI & Comprehensive Assistive Suite

Integrates multi-model text simplification and a rich suite of client-side assistive controls designed for complete blindness, low vision, dyslexia, and color vision deficiency.

  • Tiered Generative Cascade: Groq/GPT-OSS-20B (SARI: 61.75, latency: 0.45s), Gemini 3.6 Flash, and fine-tuned local T5
  • Neural Text-to-Speech: Microsoft Azure Neural TTS and ElevenLabs Multilingual v2 with variable speech rate customization
  • Assistive Controls: OpenDyslexic typography, Daltonization matrix color filters, guided reading line ruler, and hotkeys
